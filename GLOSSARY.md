# Короткий словарь SQL Server — заглядывай по мере прохождения

Этот файл — **шпаргалка**, а не обязательный материал перед первым уроком. Термины перечислены приблизительно в том порядке, в котором они появляются в курсе.

## Начало (уроки 00–03)

- **База данных (БД)** — организованное хранилище информации, например `TradingTraining`.
- **СУБД** — программа, управляющая данными. У нас Microsoft SQL Server.
- **SSMS** — приложение для подключения, запросов и управления SQL Server.
- **SQL** — язык команд к базе данных.
- **T-SQL** — разновидность SQL, используемая в Microsoft SQL Server.
- **Таблица** — набор строк с определёнными столбцами.
- **Строка / row** — одна запись, например одна сделка.
- **Столбец / column** — свойство записи, например `price`.
- **SELECT** — команда чтения; **FROM** — источник чтения; **WHERE** — условия отбора.
- **ORDER BY** — сортировка результата; **TOP** — ограничение количества выводимых строк.
- **Тип данных** — правило, какие значения можно хранить в столбце: INT, DECIMAL, VARCHAR, DATE.
- **NULL** — значение не задано/неизвестно; это не 0 и не пустая строка.

## Структура и запись (уроки 04–08)

- **Первичный ключ / PK** — поле или набор полей, однозначно идентифицирующих строку.
- **Внешний ключ / FK** — ссылка из одной таблицы на допустимую запись другой.
- **Связь 1:N** — одной записи слева может соответствовать много записей справа.
- **Схема / schema** — раздел для объектов БД; `dbo` в `dbo.trades`.
- **CREATE TABLE** — создать таблицу.
- **INSERT** — добавить строку; **UPDATE** — изменить; **DELETE** — удалить.
- **NOT NULL** — поле обязательно; **CHECK** — ограничение допустимых значений.
- **CONSTRAINT** — именованное правило на таблицу/столбцы, например `CK_trades_quantity`.
- **JOIN** — получить строки из нескольких таблиц по условию сопоставления.
- **GROUP BY** — группировать записи для подсчёта; **HAVING** — отбирать готовые группы.
- **Транзакция** — набор изменений, который можно зафиксировать (COMMIT) или откатить (ROLLBACK).

## Аналитика и проектирование (уроки 09–12)

- **Подзапрос** — SELECT внутри другого запроса.
- **CTE** — именованный этап одного SQL-запроса (`WITH ... AS`).
- **Оконная функция** — расчёт по связанным строкам без потери исходных строк.
- **VWAP / средневзвешенная цена** — средняя, в которой цены взвешены объёмом.
- **Нормализация** — проектирование таблиц, уменьшающее избыточные повторы и риск противоречий.
- **Кардинальность** — сколько строк одной таблицы соответствует одной строке другой.

## Серверная работа (уроки 13–19)

- **ACID** — четыре свойства надёжной транзакции: атомарность, согласованность, изоляция, долговечность.
- **TRY/CATCH** — обработка ошибок выполнения команд в T-SQL.
- **Блокировка / lock** — временное ограничение доступа конкурирующих операций к ресурсу.
- **Индекс** — структура для организации поиска и доступа к данным.
- **План выполнения / execution plan** — последовательность операций, выбранная сервером для SQL.
- **VIEW** — сохранённое определение запроса; **PROCEDURE** — именованная серверная команда, часто с параметрами.
- **#temp** — временная таблица для промежуточных данных.
- **Login** — учётная запись входа на сервер; **user** — пользователь внутри базы; **role** — набор разрешений.
- **Backup / restore** — резервная копия / восстановление базы.
- **RPO** — допустимая потеря данных по времени; **RTO** — допустимое время восстановления.
- **Зерно данных** — смысл одной строки в отчёте (одна сделка, один счёт за день и т. п.).
- **Идемпотентность загрузки** — повторный приём уже обработанных данных не приводит к дублированию факта.
