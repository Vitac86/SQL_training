# SQL Trainer Android

Автономный Android MVP. Откройте android/ в Android Studio, дождитесь Gradle Sync и запустите app на Android 8.0+ (API 26). Для APK: Build → Build APK(s).

## Важное ограничение
Автономный движок — SQLite, встроенный в Android, а не Microsoft SQL Server. Небольшой адаптер переводит некоторые конструкции (TOP, dbo., N-строки, ISNULL, LEN, GETDATE, GO/USE), но это не полная реализация T-SQL. Хранимые процедуры, TRY/CATCH, серверные блокировки, execution plans, права и backup SQL Server не эмулируются. Для проверки настоящего T-SQL используйте SQL Server/SSMS.

## В MVP
Локальная копия данных репозитория (12 инструментов, 6 счетов, 230 сделок, 429 дневных цен и 429 записей ликвидности), SQL-редактор, результаты, ошибки, 25 тем, 5 практических задач, история текущего сеанса и прогресс текущего сеанса. Это исходная версия для дальнейшей разработки, не релизный APK.
