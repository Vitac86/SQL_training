# SQL Trainer — автономное обучение SQL для Android

**Версия 0.6.0.** Android-приложение на Kotlin/Jetpack Compose с локальной SQLite-базой и учебными материалами SQL_training.

## Обновления через GitHub

В верхней панели добавлена кнопка **«Проверить обновления через GitHub»**. Открой её, чтобы проверить последний GitHub Release, посмотреть изменения, скачать новую версию и передать APK системному установщику. Без разрешения пользователя приложение ничего не установит.

**Важно:** для работы обновлений нужен хотя бы один **подписанный GitHub Release**; на данный момент APK публиковались только как артефакты Actions. [Инструкция по однократной настройке подписанных релизов](RELEASING.md). Пока Releases нет, кнопка открывает список сборок GitHub Actions.

Все версии APK должны иметь одну и ту же подпись. Старые debug APK из GitHub Actions могли быть подписаны другим ключом, поэтому **первая установка подписанного релиза может потребовать удаления старой версии с потерей данных**. После этого подписанные тем же ключом обновления устанавливаются поверх текущей версии.

## Учебная программа

- 32 темы с пояснениями, примерами, разбором ошибок и вопросами для самопроверки.
- 198 SQL-задач, распределённых по урокам с учётом необходимых знаний. Старые ID задач не изменились, поэтому сохранённый прогресс остаётся действительным.
- 12 тематических направлений: основы, WHERE, CASE/NULL, агрегаты, JOIN, даты, подзапросы, CTE, оконные функции, брокерская аналитика, контроль качества данных и UNION.
- Три последовательные подсказки, эталонный SQL и объяснение решения.
- Навигация «Назад / К списку / Далее» из любой задачи, без необходимости сначала решить её.
- Порядковый номер внутри урока, группировка по урокам, «Продолжить» с ближайшей нерешённой задачи.
- Сохранение отдельных черновиков SQL для каждой задачи, чтобы не терять начатое при переключении.
- Поиск и фильтры по сложности и статусу, случайная задача.
- Автоматическая проверка запросов на отдельной SQLite-базе с исходными данными.
- Прогресс по каждому уроку: статус теории отдельно от количества проверенных задач.
- В уроке о сортировке показано отличие **SQL Server TOP (3)** от **SQLite LIMIT 3**. Оба варианта поддерживаются адаптером Android.

## Редактор и база

- Подсветка SQL, номера строк и подсказки имён таблиц и столбцов.
- Просмотр схемы БД, история и сохранённые запросы.
- Ошибки SQL и сообщения проверки закрываются отдельно, без сброса базы. При редактировании запроса уведомления автоматически исчезают.
- Экран практики прокручивается целиком; задание и таблицу результатов можно свернуть.
- Редактор SQL имеет фиксированную удобную высоту (300 dp), увеличивается по кнопке и не сжимается после проверки. При открытой клавиатуре нижняя навигация скрывается, освобождая место для набора.
- Таблица результатов, копирование результатов и самостоятельное выполнение SQL.
- Исходные данные: 12 инструментов, 6 счетов, 230 сделок, 429 дневных цен и 429 записей ликвидности.

## Сборка и скачивание

Для разработки открой `android/` в Android Studio (Android 8.0+). [CI-сборки debug APK](https://github.com/Vitac86/SQL_training/actions/workflows/android.yml) доступны в разделе Artifacts последнего успешного запуска. Подписанные версии после первоначальной настройки будут доступны в [GitHub Releases](https://github.com/Vitac86/SQL_training/releases).

CI запускает `python3 scripts/verify_practice.py`, Kotlin unit-тесты и `assembleDebug`. Workflow публикации тегов дополнительно выпускает подписанный `sql-trainer.apk`.

## Диалект SQL — важное ограничение

На телефоне используется **SQLite**, а не Microsoft SQL Server. Поддерживается только часть синтаксиса T-SQL (`TOP`, `dbo.`, `ISNULL`, `GETDATE`, `GO`, `USE`). Серверные процедуры, блокировки, планы выполнения SQL Server и специфические типы не эмулируются; для настоящего T-SQL используй SQL Server и SSMS.

Учебные данные синтетические. `quantity*price` не всегда соответствует экономически корректному рублёвому обороту разных инструментов.

## Ограничения

- Работа с сетью нужна только по нажатию кнопки обновления; сам SQL-тренажёр офлайн.
- Проверка задания сравнивает столбцы, значения и порядок строк с эталонной выборкой.
- Не более 500 строк в проверяемом результате.
- Debug APK из Actions не является официальным подписанным релизом.
