# SQL Trainer — автономное обучение SQL для Android

**Версия 0.8.0.** Android-приложение на Kotlin/Jetpack Compose с локальной SQLite-базой и учебными материалами SQL_training.

## Обновлённый мобильный маршрут — v0.8.0

В приложении используется выбранная иконка: светящаяся зелёная надпись SQL в стиле слизи. Цветная иконка включена в APK и отображается в верхней панели.

**Мобильный курс: 21 последовательный урок и 168 задач.** Содержание ограничено устройством таблиц, основами SQL и написанием SELECT-запросов: фильтрацией, сортировкой, функциями, ключами, JOIN, группировкой, подзапросами, CTE, CASE, датами и оконными функциями. Индексы, транзакции, представления и специализированная брокерская аналитика остаются в десктопном курсе SQL Server, исходные материалы и задания из репозитория не удаляются.

Единый порядок для каждой темы:

1. **Материал:** подробные разделы курса без повторного верхнего брифа, с обозначением, где T-SQL, а где SQLite.
2. **Свой SQL:** пустой редактор или готовый пример; из редактора можно вернуться к материалу или перейти к задачам.
3. **Проверяемые задачи:** все упражнения конкретного урока. У каждой задачи сохранён отдельный черновик.
4. **Переход:** последняя успешно решённая задача автоматически завершает урок. «Продолжить обучение» открывает следующую незавершённую тему.

Нет ручного флага «Теория изучена». Статус **«Урок освоен»** рассчитывается только по успешным проверкам всех заданий урока. Старые ID и сохранённые результаты не удаляются; прогресс по исключённым из мобильного маршрута продвинутым задачам остаётся в локальном хранилище, но не учитывается в мобильной статистике.

## Обновления через GitHub

В верхней панели добавлена кнопка **«Проверить обновления через GitHub»**. Открой её, чтобы проверить последний GitHub Release, посмотреть изменения, скачать новую версию и передать APK системному установщику. Без разрешения пользователя приложение ничего не установит.

**Важно:** для работы обновлений нужен хотя бы один **подписанный GitHub Release**; на данный момент APK публиковались только как артефакты Actions. [Инструкция по однократной настройке подписанных релизов](RELEASING.md). Пока Releases нет, кнопка открывает список сборок GitHub Actions.

Все версии APK должны иметь одну и ту же подпись. Старые debug APK из GitHub Actions могли быть подписаны другим ключом, поэтому **первая установка подписанного релиза может потребовать удаления старой версии с потерей данных**. После этого подписанные тем же ключом обновления устанавливаются поверх текущей версии.

## Подробная теория: SQL Server против SQLite

**21 урок мобильного маршрута содержит развёрнутые объяснения на основе 21 урока десктопного курса SQL Server/SSMS.** В комплекте с APK, полностью офлайн, доступны более 150 тематических разделов. Развёрнутые фрагменты перенесены по смыслу, чтобы не ломать порядок изучения; дополнения мобильного курса имеют отдельную маркировку.

На экране каждого урока теперь явно разделены:

- **SQL Server / SSMS** — исходный T-SQL десктопного курса, с отдельной подписью над каждым фрагментом кода; такие примеры не следует бездумно запускать на SQLite.
- **SQLite / Android** — исполняемый на телефоне пример; кнопка лишь переносит SQL в редактор, автоматического исполнения нет.
- **Адаптация синтаксиса** — отдельный блок с объяснением, где диалекты совпадают, где различаются и что именно делает адаптер.
- **Проверка понимания** — вопрос с раскрываемым ответом и выход на задачи по этому уроку.

В частности, на уровне конкретных уроков разъяснены `TOP (n)` против `LIMIT n`, `dbo.`, `DATE/DECIMAL` против текстовых дат и динамической типизации SQLite, `CREATE OR ALTER VIEW` против `CREATE VIEW`, отличие планов SQL Server от `EXPLAIN QUERY PLAN`, а также отсутствие в Android-движке T-SQL `TRY/CATCH` и серверных блокировок.

**Не всякая конструкция из десктопного курса исполнима в Android.** Частичный адаптер — это не реализация Microsoft SQL Server. В редакторе практики можно развернуть карточку задачи и увидеть особенности диалекта текущей темы.

Файлы содержания: `app/src/main/assets/lesson_readings.json` (фрагменты исходного десктопного курса и помеченные дополнения), `lesson_dialects.json` (границы адаптации) и `lesson_guides.json` (разборы и самопроверка). Синхронность исходников контролирует `scripts/verify_lesson_content.py`.

## Учебная программа

- 21 тема с развёрнутыми разделами из десктопного курса, разбором SQL Server/SQLite, примерами, ошибками и вопросами для самопроверки.
- 168 мобильных SQL-задач (198 в полном каталоге репозитория), распределённых по урокам с учётом необходимых знаний. Старые ID задач не изменились, поэтому сохранённый прогресс остаётся действительным.
- 12 тематических направлений: основы, WHERE, CASE/NULL, агрегаты, JOIN, даты, подзапросы, CTE, оконные функции, брокерская аналитика, контроль качества данных и UNION.
- Три последовательные подсказки, эталонный SQL и объяснение решения.
- Навигация «Назад / К списку / Далее» из любой задачи, без необходимости сначала решить её.
- Порядковый номер внутри урока, группировка по урокам, «Продолжить» с ближайшей нерешённой задачи.
- Сохранение отдельных черновиков SQL для каждой задачи, чтобы не терять начатое при переключении.
- Поиск и фильтры по сложности и статусу, случайная задача.
- Автоматическая проверка запросов на отдельной SQLite-базе с исходными данными.
- Прогресс по каждому уроку вычисляется автоматически, без ручного подтверждения изучения теории.
- В уроке о сортировке показано отличие **SQL Server TOP (3)** от **SQLite LIMIT 3**. Оба варианта поддерживаются адаптером Android.

## Редактор и база

- Подсветка SQL, номера строк и подсказки имён таблиц и столбцов.
- Просмотр схемы БД, история и сохранённые запросы.
- Ошибки SQL и сообщения проверки закрываются отдельно, без сброса базы. При редактировании запроса уведомления автоматически исчезают.
- Экран практики прокручивается целиком; задание и таблицу результатов можно свернуть.
- Редактор SQL имеет фиксированную удобную высоту (300 dp), увеличивается по кнопке и не сжимается после проверки. При открытой клавиатуре нижняя навигация скрывается, освобождая место для набора.
- Таблица результатов, копирование результатов и самостоятельное выполнение SQL.
- Исходные данные: 12 инструментов, 6 счетов, 230 сделок, 429 дневных цен и 429 записей ликвидности.

Для разработки открой `android/` в Android Studio (Android 8.0+). [CI-сборки debug APK](https://github.com/Vitac86/SQL_training/actions/workflows/android.yml) доступны в разделе Artifacts последнего успешного запуска. Подписанные версии после первоначальной настройки будут доступны в [GitHub Releases](https://github.com/Vitac86/SQL_training/releases).

CI запускает `python3 scripts/verify_practice.py`, `python3 scripts/verify_lesson_content.py`, Kotlin unit-тесты и `assembleDebug`. Workflow публикации тегов дополнительно выпускает подписанный `sql-trainer.apk`.

## Диалект SQL — важное ограничение

На телефоне используется **SQLite**, а не Microsoft SQL Server. Поддерживается только часть синтаксиса T-SQL (`TOP`, `dbo.`, `ISNULL`, `GETDATE`, `GO`, `USE`). Серверные процедуры, блокировки, планы выполнения SQL Server и специфические типы не эмулируются; для настоящего T-SQL используй SQL Server и SSMS.

Учебные данные синтетические. `quantity*price` не всегда соответствует экономически корректному рублёвому обороту разных инструментов.

## Ограничения

- Работа с сетью нужна только по нажатию кнопки обновления; сам SQL-тренажёр офлайн.
- Проверка задания сравнивает столбцы, значения и порядок строк с эталонной выборкой.
- Не более 500 строк в проверяемом результате.
- Debug APK из Actions не является официальным подписанным релизом.
