# SQL Trainer — автономное Android-приложение

Версия **0.3.0**: усовершенствованный редактор для самостоятельной практики SQL.

## Возможности

- Работа офлайн без регистрации и внешнего сервера, данные на телефоне.
- Подсветка SQL, номера строк и горизонтальная прокрутка длинного запроса.
- Подсказки ключевых слов, таблиц и столбцов на основе локальной схемы.
- Просмотр всех таблиц и колонок базы прямо из редактора.
- Сохранение SQL по имени, открытие, удаление и восстановление последнего текста.
- История последних 50 запросов между запусками.
- Таблица результатов с копированием показанных строк вместе с заголовками.
- Объяснение типичных ошибок SQL и нарушений CHECK, FK и UNIQUE.
- 32 урока по SQL, включая брокерскую аналитику; 9 практических заданий.
- Проверка практики в отдельном READ_ONLY-подключении, без изменения базы.
- Сохранение прогресса и решённых задач между запусками.
- Подтверждение перед сбросом учебной базы; история и сохранённые SQL остаются.

Исходные данные: 12 инструментов, 6 счетов, 230 сделок, 429 дневных цен, 429 записей ликвидности.

## Установка

Открой [Android build](https://github.com/Vitac86/SQL_training/actions/workflows/android.yml), выбери последний успешный запуск. В Artifacts скачай архив `sql-trainer-debug-apk`, распакуй и установи `app-debug.apk` на Android.

Для разработки открой папку `android/` в Android Studio; требуется Android 8.0+ (API 26).

GitHub Actions запускает unit-тесты SQL-парсера и адаптера, затем собирает APK.

## Диалект SQL

Встроенный движок — **SQLite, не Microsoft SQL Server**. Некоторые конструкции T-SQL переводятся (TOP, dbo., ISNULL, GETDATE, GO, USE), но полная совместимость отсутствует. Серверные процедуры, SQL Server TRY/CATCH, блокировки, планы выполнения, серверные права и backup не эмулируются.

Для проверки настоящего T-SQL используй SQL Server/SSMS.

## Ограничения

- Подсказки основаны на названиях известных таблиц и слов. Это не полноценный SQL Language Server.
- Автоматическая проверка сравнивает состав столбцов и результирующие строки, включая порядок строк.
- Максимум 500 строк на один результат. Копирование экспортирует показанные строки.
- Транзакцию запускай полностью (BEGIN + COMMIT или ROLLBACK); незавершённая транзакция автоматически откатывается.
- Сборка debug APK предназначена для личного тестирования, не для Google Play.
