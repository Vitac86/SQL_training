# SQL Trainer — Android

Автономное Android-приложение для изучения SQL на учебной базе из этого репозитория.

## Что есть в версии 0.2

- Локальная SQLite-база: instruments, accounts, trades, daily_prices, liquidity.
- SQL-редактор с выполнением одиночных запросов и скриптов из нескольких команд.
- Табличный результат, время выполнения и сообщения об ошибках.
- Быстрые вставки SQL-конструкций.
- 32 урока: основы SQL, JOIN, агрегаты, CTE, оконные функции, транзакции и брокерская аналитика.
- 9 практических задач с автоматической сверкой результата с эталонной выборкой.
- История запросов, пройденные темы и решённые задачи сохраняются между запусками.
- Сброс учебной базы к исходному состоянию.

## Сборка и установка

1. Открой папку `android/` в Android Studio.
2. Дождись Gradle Sync.
3. Запусти конфигурацию `app` на Android 8.0+ (API 26).
4. APK можно скачать из GitHub Actions: Actions → Android build → успешный запуск → Artifacts → `sql-trainer-debug-apk`.

GitHub Actions автоматически собирает debug APK при изменениях в папке android.

## Диалект SQL — важно

Движок приложения — SQLite, встроенный в Android. Это не Microsoft SQL Server и не полная реализация T-SQL. Небольшой адаптер преобразует отдельные распространённые конструкции (TOP, dbo., N-строки, ISNULL, LEN, GETDATE, GO/USE). Серверные функции SQL Server — хранимые процедуры, TRY/CATCH, блокировки, планы выполнения, разрешения, backup и особенности T-SQL — не эмулируются. Для проверки реального T-SQL используй SQL Server и SSMS.

## Известные ограничения

- Подсветка синтаксиса и полноценное контекстное автодополнение пока не реализованы; есть быстрые вставки ключевых слов.
- История хранит последние 50 запросов.
- Практические задания сравнивают столбцы и строки с эталонной выборкой; порядок строк имеет значение.
- Транзакционный скрипт должен содержать BEGIN и COMMIT либо ROLLBACK в одном запуске.
- Это debug-сборка, не подписанный релиз для Google Play.
