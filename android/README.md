# SQL Trainer — автономное обучение SQL для Android

**Версия 0.4.0.** Офлайн-приложение на Kotlin/Jetpack Compose с локальной SQLite-базой и материалами из репозитория SQL_training.

## Учебная программа

- **32 темы с подробными пояснениями:** что означает конструкция, зачем она нужна, разбор по шагам, типичные ошибки, проверка понимания с ответом
- **186 практических SQL-задач:** 39 базовых, 82 среднего уровня, 65 сложных
- **12 тематических разделов:** основы и SELECT, WHERE, строки/CASE/NULL, агрегаты, JOIN, даты, подзапросы, CTE, окна, брокерская аналитика, качество данных, UNION
- **Три подсказки** к каждой задаче, затем по желанию — эталонный SQL и разбор решения
- Поиск задач, фильтрация по теме, сложности и решённости, случайная задача и переход к следующей
- Автоматическая проверка результата с диагностикой отличий по столбцам и строкам
- Прогресс по темам и решённым заданиям сохраняется между запусками

Все задания используют те же пять таблиц, что и настольный курс: 12 инструментов, 6 счетов, 230 сделок, 429 дневных цен и 429 записей ликвидности.

## Безопасность тренажёра

Кнопка **«Проверить»** создаёт отдельную временную SQLite-базу с исходными данными и исполняет запросы на ней в режиме `query_only`. Так задания не зависят от того, что ты ранее изменял в свободном редакторе. Для проверки допускается один SELECT или WITH, вывод до 500 строк. SQL-результат сравнивается с эталонным по заголовкам, значениям и порядку. Экономически разные формулы, приводящие случайно к тому же ответу на фиксированных данных, могут быть зачтены — как и в любом тренажёре, это не формальная проверка доказательства корректности алгоритма.

Эталонные SQL-запросы и решения находятся в `app/src/main/assets/practice_tasks.json`. Гайды по темам — в `app/src/main/assets/lesson_guides.json`. Стабильные ID первых девяти задач сохранены для совместимости с предыдущим прогрессом.

## Установка

Открой [Android build](https://github.com/Vitac86/SQL_training/actions/workflows/android.yml), выбери последний **успешный** запуск, в Artifacts скачай `sql-trainer-debug-apk`, распакуй `app-debug.apk` и установи на телефон.

Для разработки: открой папку `android/` в Android Studio, выбери `app`, Gradle Sync → Run. Минимальная версия Android: API 26, но для оконных функций на системном SQLite требуется версия SQLite 3.25+ (обычно Android 10 и новее).

## Проверки проекта

GitHub Actions выполняет:

1. `python3 scripts/verify_practice.py` — все 186 эталонных SQL-запросов на исходном SQLite-наборе и проверку структуры каталога
2. `gradle :app:testDebugUnitTest` — тесты парсера и адаптера
3. `gradle :app:assembleDebug` — сборку APK

## Важно о диалекте

Автономное приложение исполняет запросы через **SQLite**, не Microsoft SQL Server. Адаптер поддерживает отдельные формы T-SQL (`TOP`, `dbo.`, `ISNULL`, `GETDATE`, `GO`, `USE`), но не серверные процедуры, T-SQL TRY/CATCH, управление правами, блокировки и планы SQL Server. Для проверки настоящего T-SQL необходим SQL Server/SSMS.

Финансовые данные синтетические. `quantity*price` не обязательно является корректным рублёвым оборотом между разными классами активов.

## Ограничения

- Автодополнение и подсветка в редакторе упрощённые, это не SQL Language Server.
- Эталонная проверка на фиксированном наборе данных не гарантирует универсальной правильности SQL.
- Запросы с результатом более 500 строк не проверяются; сократи выборку.
- История и персональные запросы хранятся на устройстве.
- Debug APK предназначен для личного использования, не для публикации в Google Play.
