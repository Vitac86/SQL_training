# SQL Trainer — Android

Автономное Android-приложение для изучения SQL на учебной базе из этого репозитория.

## Что есть в версии 0.2

- Локальная SQLite-база: instruments, accounts, trades, daily_prices, liquidity.
- Редактор SQL с запуском нескольких команд в одном скрипте.
- Табличный результат, время выполнения и сообщения об ошибках.
- Быстрые вставки ключевых конструкций SQL.
- 25 уроков: от SELECT и фильтрации до CTE, оконных функций, индексов и транзакций.
- Практические задачи с автоматической сверкой результата с эталонным запросом.
- История запросов и прогресс сохраняются между запусками.
- Полный сброс учебной базы к начальному состоянию.

## Сборка

1. Открой папку `android/` в Android Studio.
2. Дождись Gradle Sync.
3. Запусти конфигурацию `app` на Android 8.0+ (API 26).
4. Либо скачай APK из GitHub Actions: Actions → Android build → последний успешный запуск → Artifacts → `sql-trainer-debug-apk`.

CI собирает debug APK при изменениях в папке android.

## Диалект SQL — важно

Движок приложения — SQLite, встроенный в Android. Это не Microsoft SQL Server и не полная реализация T-SQL. Небольшой адаптер преобразует отдельные распространённые конструкции (TOP, dbo., N-строки, ISNULL, LEN, GETDATE, GO/USE). Серверные функции SQL Server — хранимые процедуры, TRY/CATCH, блокировки, планы выполнения, разрешения, backup и особенности T-SQL — не эмулируются. Для проверки реального T-SQL используй SQL Server и SSMS.

## Ограничения текущего MVP

- Подсветка синтаксиса и полноценное автодополнение пока не реализованы; есть быстрые вставки ключевых слов.
- История хранит последние 50 запросов.
- Практические задания сравнивают результирующие столбцы и строки с эталонной выборкой. Эквивалентные запросы с иным порядком строк могут потребовать такого же ORDER BY, как в задании.
- Это debug-сборка, не подписанный релиз для Google Play.
