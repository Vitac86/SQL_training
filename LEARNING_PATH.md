# Маршрут курса

Полный путь обучения. Уроки 0-4 реализованы подробно (`lessons/`). Остальные пункты —
запланированный маршрут на будущее, пока без готовых материалов.

## Реализовано подробно

- **0. Создание БД, ключи, схема и ограничения** — `lessons/00_создание_базы_и_ключи.md`.
  Своими руками создать базу, `CREATE TABLE`, типы данных, `PRIMARY KEY`, `UNIQUE`,
  `INTEGER PRIMARY KEY`/rowid, `FOREIGN KEY`, отличие `FOREIGN KEY` от `JOIN`, ручной JOIN,
  все ограничения (`NOT NULL`, `CHECK`, `DEFAULT`), связь один-ко-многим, `INSERT`/`UPDATE`/
  `DELETE`, опасность отсутствующего `WHERE`, `DELETE` и `FOREIGN KEY`, `ALTER TABLE`/
  `DROP TABLE`, транзакции (`BEGIN`/`ROLLBACK`/`COMMIT`), нормализация на пальцах, составные
  ключи, базовое представление об индексах.

- **1. Устройство готовой БД** — `lessons/01_что_такое_база_данных.md`. Переход к
  `trading_training.db`, повторение терминов на реальных данных, первый `SELECT`.

- **2. SELECT и фильтрация** — `lessons/02_select_where_order_by.md`. `SELECT`, `DISTINCT`,
  `AS`, `WHERE` и операторы сравнения, `AND`/`OR`/`NOT`, `IN`, `BETWEEN`, `LIKE`,
  `IS NULL`/`IS NOT NULL`, `ORDER BY`, `LIMIT`, вычисляемые колонки.

- **3. Агрегаты** — `lessons/03_агрегаты_group_by.md`. `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`,
  `GROUP BY`, `HAVING`, `CASE` на торговых примерах.

- **4. JOIN** — `lessons/04_join.md`. `INNER JOIN`, `LEFT JOIN`, разбор по шагам, инструмент
  и счёт без сделок, краткое знакомство с `RIGHT JOIN`/`FULL OUTER JOIN`.

## Запланировано (пока без готовых уроков)

- **5. Изменение данных на практике** — более сложные сценарии `INSERT`/`UPDATE`/`DELETE`,
  multi-row insert, `INSERT ... SELECT`.
- **6. Транзакции глубже** — поведение при ошибках внутри транзакции, `SAVEPOINT`.
- **7. Подзапросы и CTE** — подзапросы в `WHERE`/`FROM`, `WITH ... AS` (common table
  expressions), когда CTE читается понятнее, чем вложенный подзапрос.
- **8. Оконные функции** — `OVER`, `PARTITION BY`, `ROW_NUMBER`, `RANK`, скользящие расчёты
  (например, скользящее среднее цены).
- **9. Основы Python** — синтаксис языка вне контекста SQL, если требуется отдельное
  усиление перед следующими шагами.
- **10. SQLite через Python** — углублённо: транзакции из Python, обработка ошибок,
  `executemany`, работа с большими выборками.
- **11. pandas** — продолжение `03_pandas_analysis.py`: `merge`, `pivot_table`, работа с
  индексами, временными рядами средствами pandas.
- **12. Excel/CSV** — продолжение `04_import_excel.py`: сложные кейсы очистки данных,
  множественные листы Excel, экспорт обратно в Excel/CSV.
- **13. Внешние финансовые данные** — подключение реальных источников данных (котировки,
  исторические цены), их приведение к формату этого учебного проекта.
- **14. Итоговый торговый мини-проект** — самостоятельная работа: спроектировать и
  реализовать небольшое расширение базы (например, таблицу лимитов или позиций) и написать
  к нему аналитику на SQL и pandas.

## Как использовать этот файл

Когда дойдёте до пункта без готового урока — это сигнал вернуться и попросить помощь в
разработке материалов именно для этого шага, основываясь на том, что вы уже прошли.
