# Маршрут обучения: T-SQL + фундаментальная теория СУБД

**Текущая версия — SQL Server / SSMS**. Уроки идут последовательно: теория → работающий пример в SSMS → задания → самопроверка. Новые запросы выполняй в `practice.sql`. Когда видишь опасное изменение данных, используй транзакцию с `ROLLBACK`.

## Блок A. Как устроены БД

- **00 — [Введение в СУБД](lessons/00_введение_в_субд.md).** Что такое БД, СУБД, SQL, T-SQL, сервер/клиент, OLTP/OLAP, таблица, строка, схема, каталог; знакомство с SSMS.
- **01 — [Реляционная модель и структура БД](lessons/01_модель_данных_и_ключи.md).** Сущности, связи, PK/FK, 1:N/M:N, ограничения, основные типы данных, ER-модель и нормализация.
- **02 — [Чтение данных и логика SQL](lessons/02_select_и_фильтрация.md).** SELECT, FROM, WHERE, ORDER BY, DISTINCT, TOP, NULL, LIKE, логический порядок SQL.

## Блок B. Запросы к данным

- **03 — [Агрегация](lessons/03_агрегаты_group_by.md).** GROUP BY, HAVING, COUNT, SUM, AVG, CASE, средневзвешенная цена.
- **04 — [Соединения](lessons/04_соединения_join.md).** JOIN, LEFT/FULL, многоколоночные ключи, фан-аут, антисоединения, «нулевые» счета.
- **05 — [Модификация данных](lessons/05_insert_update_delete.md).** INSERT, UPDATE, DELETE, OUTPUT, CHECK/FK, защита от ошибок.
- **06 — [Подзапросы и CTE](lessons/06_подзапросы_cte.md).** EXISTS, NOT EXISTS, коррелированные подзапросы, CTE, APPLY.
- **07 — [Оконные функции](lessons/07_оконные_функции.md).** ROW_NUMBER, RANK, LAG, LEAD, SUM OVER, оконные рамки.
- **08 — [Финансовые данные и даты](lessons/08_даты_и_числа.md).** DECIMAL vs FLOAT, даты, TRY_CONVERT, NULLIF, границы применимости оборота и VWAP.

## Блок C. Конструирование и эксплуатация

- **09 — [Нормализация и моделирование](lessons/09_проектирование_и_нормализация.md).** 1NF–3NF, функциональные зависимости, справочники, историзация, суррогатные ключи.
- **10 — [Транзакции и ACID](lessons/10_транзакции_acid.md).** BEGIN TRAN/COMMIT/ROLLBACK, TRY/CATCH, XACT_ABORT, атомарность.
- **11 — [Изоляция, блокировки, конкурентность](lessons/11_изоляция_и_блокировки.md).** Read Committed, SNAPSHOT, deadlock, lost update, практические границы.
- **12 — [Индексы и планы выполнения](lessons/12_индексы_и_планы.md).** Clustered/nonclustered, composite, INCLUDE, SARGability, EXPLAIN-аналог (actual execution plan).
- **13 — [Представления, процедуры, временные таблицы](lessons/13_views_procedures_temp.md).** VIEW, PROCEDURE, параметры, #temp, табличные выражения.
- **14 — [Схемы, безопасность и доступ](lessons/14_безопасность_и_доступ.md).** Пользователь и login, роли, GRANT, принцип минимальных прав.
- **15 — [Резервирование и восстановление](lessons/15_backup_restore.md).** Backup, restore, recovery model, RPO/RTO, проверка резервной копии.
- **16 — [Качество данных и диагностика](lessons/16_качество_и_диагностика.md).** Контроль целостности, дубли, расхождения, системные представления, базовая диагностика.

## Блок D. Применение

- **17 — [Итоговый проект](lessons/17_итоговый_проект.md).** Поручения на сделки, исполнения, ограничения, отчёты по портфелю, контроль ошибок.

## Как учиться

Для каждого урока: сначала своими словами объясни теорию (почему так), затем выполни примеры в SSMS, предскажи ожидаемый результат, выполни 2–4 задания без подсказок и только потом проверь себя. Если запрос возвращает неожиданные строки, выясни причину, а не подгоняй SQL под ожидаемое число.

Материалы начальной версии SQLite сохранены в `archive/sqlite/` только для истории. Изучение текущей программы **не требует** Python/SQLite.
