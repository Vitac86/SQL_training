# Ответы к уроку 09 — подзапросы и CTE

[Вернуться к уроку](../09_подзапросы_cte.md)

## 1. Сделки с ценой выше общей средней

```sql
USE TradingTraining;
SELECT trade_id, price
FROM dbo.trades
WHERE price > (SELECT AVG(price) FROM dbo.trades)
ORDER BY price DESC, trade_id;
```

Внутренний SELECT вычисляет **одно число — среднюю цену**. Внешний SELECT оставляет сделки выше этого числа. Разные инструменты имеют разные цены, поэтому результат — только учебный пример синтаксиса.

## 2. Счета без сделок: NOT EXISTS

```sql
SELECT a.account_name
FROM dbo.accounts AS a
WHERE NOT EXISTS (
    SELECT 1
    FROM dbo.trades AS t
    WHERE t.account_id = a.account_id
);
```

Результат — **ACC-DORMANT**. NOT EXISTS означает, что **не найдено ни одной** сделки соответствующего счёта.

## 3. CTE — суммы комиссий с названиями счетов

```sql
WITH fees_by_account AS (
    SELECT account_id, SUM(commission) AS total_fee
    FROM dbo.trades
    GROUP BY account_id
)
SELECT a.account_name,
       COALESCE(f.total_fee, 0) AS total_fee
FROM dbo.accounts AS a
LEFT JOIN fees_by_account AS f ON f.account_id = a.account_id
ORDER BY a.account_name;
```

Должны быть **6 счетов**, в том числе `ACC-DORMANT` с комиссией **0**. LEFT JOIN сохраняет счёт, не имеющий записей в CTE.

## 4. CTE и CREATE TABLE

**CTE** — имя промежуточного результата, доступного только для **одного следующего SQL-оператора**. Он не создаёт постоянную пользовательскую таблицу. `CREATE TABLE` создаёт таблицу в базе, которую можно читать и изменять позднее, пока она не удалена.
