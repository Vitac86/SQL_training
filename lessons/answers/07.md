# Ответы к уроку 07 — JOIN

[Вернуться к уроку](../07_join.md)

## 1. 20 сделок с названиями

```sql
USE TradingTraining;
SELECT TOP (20) t.trade_id, a.account_name, i.ticker,
                t.side, t.quantity, t.price
FROM dbo.trades AS t
JOIN dbo.accounts AS a ON a.account_id = t.account_id
JOIN dbo.instruments AS i ON i.instrument_id = t.instrument_id
ORDER BY t.trade_id;
```

**20 строк**, если связь выполнена по ключам. Теперь у сделки есть и название счёта, и тикер.

## 2. Инструменты без сделок

```sql
SELECT i.ticker
FROM dbo.instruments AS i
LEFT JOIN dbo.trades AS t ON t.instrument_id = i.instrument_id
WHERE t.trade_id IS NULL;
```

Ожидается **TEST0**. LEFT JOIN сохраняет все инструменты; для не найденной сделки `t.trade_id` становится NULL.

## 3. Счета без сделок

```sql
SELECT a.account_name
FROM dbo.accounts AS a
LEFT JOIN dbo.trades AS t ON t.account_id = a.account_id
WHERE t.trade_id IS NULL;
```

Ожидается **ACC-DORMANT**.

## 4. Количество сделок по каждому тикеру, включая TEST0

```sql
SELECT i.ticker, COUNT(t.trade_id) AS trade_count
FROM dbo.instruments AS i
LEFT JOIN dbo.trades AS t ON t.instrument_id = i.instrument_id
GROUP BY i.ticker
ORDER BY i.ticker;
```

Должны быть **12 инструментов**, у `TEST0` — **0**. `COUNT(t.trade_id)` не считает пустую часть LEFT JOIN. `COUNT(*)` дал бы ложную единицу для TEST0.

## 5. Почему для цены закрытия нужны дата и инструмент

```sql
SELECT TOP (10) t.trade_id, t.trade_date,
                i.ticker, t.price, p.close_price
FROM dbo.trades AS t
JOIN dbo.instruments AS i ON i.instrument_id = t.instrument_id
LEFT JOIN dbo.daily_prices AS p
  ON p.instrument_id = t.instrument_id
 AND p.price_date = t.trade_date
ORDER BY t.trade_id;
```

Цена закрытия относится **к инструменту на конкретную дату**. JOIN только по `instrument_id` присоединил бы к каждой сделке все даты цен этого инструмента и искусственно размножил строки.
