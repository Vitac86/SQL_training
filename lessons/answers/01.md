# Ответы к уроку 01 — SELECT и сортировка

[Вернуться к уроку](../01_select_и_сортировка.md)

## 1. Три самые дорогие сделки

```sql
USE TradingTraining;
SELECT TOP (3) trade_id, price
FROM dbo.trades
ORDER BY price DESC, trade_id ASC;
```

Сначала SQL Server сортирует по цене от большей к меньшей. Если цены совпадают, `trade_id` задаёт определённый порядок. `TOP (3)` оставляет три первых строки в этом порядке.

## 2. Тикер и валюта каждого инструмента

```sql
SELECT ticker, currency
FROM dbo.instruments
ORDER BY ticker;
```

**12 строк**, два столбца. Сортировка по имени тикера идёт по возрастанию.

## 3. Другое имя для цены

```sql
SELECT trade_id, price AS execution_price
FROM dbo.trades
ORDER BY trade_id;
```

В результате будет заголовок `execution_price`, но в самом `dbo.trades` столбец по-прежнему называется `price`. `AS` не меняет таблицу.

## 4. Классы активов без повторов

```sql
SELECT DISTINCT asset_class
FROM dbo.instruments
ORDER BY asset_class;
```

Для исходного набора ожидаются четыре класса: `bond`, `equity`, `fx`, `money_market`. `DISTINCT` удаляет повторяющиеся значения в результате запроса.
