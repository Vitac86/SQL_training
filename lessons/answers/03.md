# Ответы к уроку 03 — типы данных

[Вернуться к уроку](../03_типы_данных.md)

## 1. Типы в dbo.accounts

В **Object Explorer → Databases → TradingTraining → Tables → dbo.accounts → Columns**:

- `account_id` — `INT`: целый номер счёта.
- `account_name` — `VARCHAR(64)`: текстовый код/имя.
- `risk_limit_rub` — `DECIMAL(19,2)`: десятичная сумма с двумя цифрами после точки.

Это видно и в исходном `database/01_schema.sql`, в команде создания таблицы `dbo.accounts`.

## 2. Подходящие типы

Для **даты исполнения без времени** — `DATE`. Если нужна дата **и время исполнения** — `DATETIME2`. Для количества целых бумаг — `INT` либо `BIGINT` в зависимости от диапазона. Для названия на русском языке — `NVARCHAR(n)`, например `NVARCHAR(200)`.

Тип выбирают по смыслу и допустимому диапазону, а не только по тому, как значение выглядит в таблице.

## 3. Сложение и объединение текста

```sql
SELECT 'A' + 'B' AS result;  -- AB
SELECT 2 + 3 AS result;      -- 5
```

Первый `+` объединяет **две строки текста**, второй складывает **числа**. Отсюда важность типов данных.

## 4. INT и FLOAT для цены

`INT` не хранит дробную часть, поэтому цена `123.45` не сохраняется как точное дробное значение. `FLOAT` хранит приблизительное двоичное число: финансовая десятичная дробь может быть представлена с небольшой погрешностью. Для точной денежной арифметики обычно используют `DECIMAL(p,s)` с согласованной политикой округления.
