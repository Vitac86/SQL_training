# Ответы к уроку 06 — агрегаты

[Вернуться к уроку](../06_агрегаты.md)

## 1. Сколько сделок по каждому инструменту

```sql
USE TradingTraining;
SELECT instrument_id, COUNT(*) AS trade_count
FROM dbo.trades
GROUP BY instrument_id
ORDER BY instrument_id;
```

Одна строка результата = **один инструмент, по которому есть сделки**. Инструмент TEST0 не попадёт: в `trades` для него нет строк (добавлять пустые инструменты через LEFT JOIN научились в уроке 07).

## 2. Средняя комиссия BUY и SELL

```sql
SELECT side, AVG(commission) AS avg_commission
FROM dbo.trades
GROUP BY side
ORDER BY side;
```

Должны быть **две строки**, по одной для BUY и SELL.

## 3. Даты с более чем пятью сделками

```sql
SELECT trade_date, COUNT(*) AS trade_count
FROM dbo.trades
GROUP BY trade_date
HAVING COUNT(*) > 5
ORDER BY trade_date;
```

`HAVING` проверяет уже **посчитанные группы**, а не исходные сделки. `WHERE COUNT(*) > 5` на этом уровне не работает.

## 4. Сумма комиссий по счетам

```sql
SELECT account_id, SUM(commission) AS total_fees
FROM dbo.trades
GROUP BY account_id
ORDER BY total_fees DESC, account_id;
```

Это сумма по **активным** счетам. Счёт `ACC-DORMANT` без сделок не появится; после LEFT JOIN его можно добавить с нулём.

## 5. Что означает одна строка при двух полях GROUP BY

```sql
SELECT account_id, trade_date,
       COUNT(*) AS trade_count
FROM dbo.trades
GROUP BY account_id, trade_date
ORDER BY account_id, trade_date;
```

Одна строка результата = **один счёт за одну дату**. Отдельные сделки этой пары сложены в одну группу.
