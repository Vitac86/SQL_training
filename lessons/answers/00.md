# Ответы к уроку 00 — первое знакомство

[Вернуться к уроку](../00_первое_знакомство.md)

**Как проверять:** сначала выполни задания в SSMS самостоятельно, затем сравни команды и результат. Все запросы ниже только читают данные.

## 1. Все счета

```sql
USE TradingTraining;
SELECT * FROM dbo.accounts;
```

Ожидается **6 строк**. `*` означает «все столбцы», а `FROM` указывает таблицу.

## 2. Тикеры и названия инструментов

```sql
SELECT ticker, [name] FROM dbo.instruments;
```

Ожидается **12 строк и 2 столбца**. Квадратные скобки вокруг `[name]` здесь позволяют явно обозначить имя столбца.

## 3. Три первые сделки

```sql
SELECT TOP (3) trade_id, trade_date, price
FROM dbo.trades
ORDER BY trade_id;
```

Должны появиться `trade_id = 1, 2, 3`. Именно `ORDER BY` определяет, какие три сделки считать первыми.

## 4. SSMS и SQL Server

**SQL Server** — серверная программа, хранящая и обрабатывающая данные. **SSMS** — интерфейс: она отправляет SQL-запрос и показывает ответ. База остаётся на сервере, если закрыть SSMS.

В SSMS для проверки полезно знать три места: **Object Explorer** (дерево баз и таблиц), **New Query** (редактор), **Results/Messages** (ответ или ошибка).
