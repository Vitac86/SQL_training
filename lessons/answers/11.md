# Ответы к уроку 11 — оконные функции

## 1. Три самые дорогие сделки каждого инструмента

```sql
USE TradingTraining;
WITH ranked AS (
    SELECT trade_id, instrument_id, price,
           ROW_NUMBER() OVER (
              PARTITION BY instrument_id
              ORDER BY price DESC, trade_id
           ) AS rn
    FROM dbo.trades
)
SELECT trade_id, instrument_id, price, rn
FROM ranked
WHERE rn <= 3
ORDER BY instrument_id, rn;
```

`ROW_NUMBER` начинает нумерацию заново для **каждого** instrument_id. CTE нужен, потому что фильтр `rn <= 3` применяется **после** вычисления номеров. У инструмента с двумя сделками было бы две строки, не три.

## 2. Предыдущая дневная цена SBER

```sql
SELECT price_date, close_price,
       LAG(close_price) OVER (ORDER BY price_date) AS previous_close
FROM dbo.daily_prices
WHERE instrument_id = 1
ORDER BY price_date;
```

Для первой даты `previous_close` равен **NULL**: предыдущего наблюдения нет.

## 3. Накопленная комиссия по счёту 2

```sql
SELECT trade_id, trade_date, commission,
       SUM(commission) OVER (
           ORDER BY trade_date, trade_id
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS cumulative_fee
FROM dbo.trades
WHERE account_id = 2
ORDER BY trade_date, trade_id;
```

В каждой следующей строке накопленный показатель — сумма комиссий **с первой сделки до текущей** для этого счёта.

## 4. Два ORDER BY в запросе с OVER

`ORDER BY` **внутри `OVER`** определяет порядок, в котором функция нумерует/сравнивает/суммирует строки. Внешний `ORDER BY` определяет порядок, в котором **показаны результирующие строки**. Они могут совпадать, но решают разные задачи.
