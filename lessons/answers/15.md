# Ответы к уроку 15 — индексы и планы выполнения

[Вернуться к уроку](../15_индексы_и_планы.md)

**Важно:** конкретный план выполнения (Seek или Scan) зависит от статистики, индексов, версии SQL Server и объёма данных. Его нельзя заранее выдать как единственно правильный.

## 1. Где найти индексы

В **Object Explorer → TradingTraining → Tables → dbo.trades → Indexes**. Либо:

```sql
USE TradingTraining;
SELECT name, type_desc, is_unique
FROM sys.indexes
WHERE object_id = OBJECT_ID(N'dbo.trades')
ORDER BY index_id;
```

Изначально есть индекс, поддерживающий `PK_trades`. Дополнительные индексы могут появиться после запуска `database/04_indexes_optional.sql`.

## 2. Как увидеть реальный план

В SSMS нажми **Ctrl+M** (Include Actual Execution Plan), затем F5:

```sql
SELECT trade_id, trade_date, price
FROM dbo.trades
WHERE instrument_id = 1
ORDER BY trade_date;
```

Открой вкладку **Execution Plan**. **Scan** — чтение множества записей/страниц; **Seek** — направленный поиск по индексу; **Sort** — отдельная сортировка. На 230 сделках Scan может оказаться рациональным. Для ответа правильно **описать то, что реально показано**, а не требовать обязательно Seek.

## 3. Проверка после дополнительных индексов

Выполни `database/04_indexes_optional.sql` **один раз** (он предусматривает проверку существования индексов). Повтори запрос и сравни: появился ли Index Seek, изменились ли логические чтения, сортировка, длительность? Даже после создания индекса SQL Server может оставить Scan — это нормально для маленькой таблицы.

## 4. Почему индексы ускоряют SELECT и замедляют запись

Индекс помогает искать нужные строки, но при каждом INSERT/UPDATE/DELETE нужно поддерживать индексную структуру. Больше индексов = больше дискового пространства и потенциально больше работы при изменениях.

## 5. Порядок столбцов для отчёта

Обычно подходит **`(account_id, trade_date)`**: сначала фильтруем один счёт (равенство), внутри него диапазон дат. Однако реальный выбор нужно подтверждать планом запросов, статистикой и нагрузкой. Это обоснованная гипотеза, не гарантия ускорения.
