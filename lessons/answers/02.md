# Ответы к уроку 02 — WHERE и NULL

[Вернуться к уроку](../02_where_и_null.md)

## 1. Продажи дороже 1000

```sql
USE TradingTraining;
SELECT trade_id, side, price
FROM dbo.trades
WHERE side = 'SELL' AND price > 1000
ORDER BY price DESC, trade_id;
```

`AND` означает «оба условия одновременно»: только продажа **и** цена больше 1000.

## 2. Облигации и инструменты денежного рынка

```sql
SELECT ticker, asset_class
FROM dbo.instruments
WHERE asset_class IN ('bond', 'money_market')
ORDER BY ticker;
```

Эквивалентная запись: `asset_class = 'bond' OR asset_class = 'money_market'`. `IN` часто короче, если проверяешь один столбец на несколько значений.

## 3. Тикеры на G

```sql
SELECT ticker FROM dbo.instruments
WHERE ticker LIKE 'G%'
ORDER BY ticker;
```

Ожидаются `GAZP` и `GMKN`. Знак `%` означает «любые символы после G».

## 4. Цены от 100 до 500

```sql
SELECT trade_id, price
FROM dbo.trades
WHERE price BETWEEN 100 AND 500
ORDER BY price, trade_id;
```

`BETWEEN` включает оба края: 100 и 500 (если такие цены есть).

## 5. Разница AND и OR

```sql
-- Только BUY, где количество больше 100:
SELECT trade_id FROM dbo.trades
WHERE side = 'BUY' AND quantity > 100;

-- Любая BUY-сделка ИЛИ сделка с количеством больше 100:
SELECT trade_id FROM dbo.trades
WHERE side = 'BUY' OR quantity > 100;
```

Во втором случае строка может пройти даже при `side='SELL'`, если `quantity>100`. Поэтому результат второго условия обычно шире.
