# Урок 07. Оконные функции: аналитика без схлопывания строк

**Цель:** вычислять ранги и динамические показатели, сохраняя детализацию.

## Группа и окно — принципиальная разница

`GROUP BY` превращает несколько строк в одну на группу. `OVER (PARTITION BY ...)` вычисляет показатель **поверх множества строк**, но оставляет каждую исходную строку.

```sql
USE TradingTraining;
SELECT t.trade_id, t.instrument_id, t.trade_date, t.price,
       ROW_NUMBER() OVER (
           PARTITION BY t.instrument_id
           ORDER BY t.trade_date DESC, t.trade_id DESC
       ) AS rn
FROM dbo.trades AS t;
```

`PARTITION BY` — виртуальное разделение на группы, `ORDER BY` внутри `OVER` — порядок вычисления в группе. Для стабильности добавляй уникальный tie-breaker (`trade_id`). `ROW_NUMBER` даёт последовательность, `RANK` оставляет пропуски при одинаковых значениях, `DENSE_RANK` — нет.

## Последняя сделка по каждому инструменту

```sql
WITH numbered AS (
  SELECT t.*,
         ROW_NUMBER() OVER (
            PARTITION BY instrument_id
            ORDER BY trade_date DESC, trade_id DESC
         ) AS rn
  FROM dbo.trades AS t
)
SELECT trade_id, instrument_id, trade_date, price
FROM numbered
WHERE rn = 1;
```

Нельзя написать `WHERE ROW_NUMBER() ... = 1` на том же уровне, потому что WHERE логически обрабатывается раньше SELECT/оконных выражений.

## LAG и дневная доходность

```sql
WITH prices AS (
  SELECT p.price_date, i.ticker, p.close_price,
         LAG(p.close_price) OVER (
            PARTITION BY i.instrument_id ORDER BY p.price_date
         ) AS prev_close
  FROM dbo.daily_prices AS p
  JOIN dbo.instruments AS i ON i.instrument_id = p.instrument_id
)
SELECT ticker, price_date, close_price, prev_close,
       100.0 * (close_price - prev_close) / NULLIF(prev_close, 0)
           AS daily_return_pct
FROM prices
WHERE ticker = 'SBER'
ORDER BY price_date;
```

Первый день получает NULL: предыдущей цены нет. `LEAD` аналогично обращается к последующей строке. Не смешивай будущие и прошлые значения в торговом сигнале (look-ahead bias).

## Рамки окна: скользящая средняя

```sql
SELECT p.price_date, p.close_price,
       AVG(p.close_price) OVER (
           PARTITION BY p.instrument_id
           ORDER BY p.price_date
           ROWS BETWEEN 4 PRECEDING AND CURRENT ROW
       ) AS sma_5_observations
FROM dbo.daily_prices AS p
WHERE p.instrument_id = 1
ORDER BY p.price_date;
```

**Пять наблюдений не обязательно равны пяти календарным дням**. При `ROWS` считаются строки; `RANGE` работает иначе. Начало ряда содержит меньше пяти наблюдений — это частичное окно.
