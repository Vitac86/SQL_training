# Урок 00. Что такое СУБД и где исполняется SQL

**Цель:** понять устройство базы данных до написания запросов. **Предусловие:** установлен SQL Server, открыто соединение SSMS; [инструкция](../SETUP_WINDOWS.md).

## Теория: разделяем пять понятий

1. **Данные** — факты о сделках, инструментах и счетах. **База данных** — организованный набор данных и объектов (таблиц, ключей, индексов, процедур).
2. **СУБД (DBMS)** — программное обеспечение, управляющее данными: хранение, контроль целостности, транзакции, конкурирующие запросы, безопасность и восстановление. Здесь — Microsoft SQL Server Database Engine, обычно служба Windows.
3. **Клиент** — программа, отправляющая запросы серверу. SSMS — клиент. Установка SSMS сама по себе **не устанавливает** Database Engine.
4. **SQL** — декларативный язык («что получить»), а не порядок перебора строк. **T-SQL** — реализация и расширения SQL в SQL Server (например, TOP, TRY/CATCH, DECLARE).
5. **Экземпляр SQL Server** содержит несколько **баз данных**, каждая — схемы и объекты; здесь `TradingTraining.dbo.trades`: `TradingTraining` — база, `dbo` — схема, `trades` — таблица.

## Как проходит запрос

```text
человек -> SSMS -> подключение -> SQL Server Database Engine
                                    |
                    парсер -> оптимизатор -> план -> чтение страниц/индексов
                                    |
                           набор строк -> SSMS
```

Оптимизатор сам выбирает физический способ выполнения. `SELECT` не обязательно «идёт по строкам» в записанном порядке. Без явного `ORDER BY` **порядок результата не гарантируется**.

**OLTP** — много коротких транзакций и корректная запись операций (торговая система). **OLAP** — аналитические запросы по большому массиву; курс показывает приёмы для обоих сценариев, но локальная база — учебная.

## Практика в SSMS

Нажми **New Query** и выполни (**F5**):

```sql
SELECT @@SERVERNAME AS server_name,
       DB_NAME() AS current_database,
       @@VERSION AS server_version;
GO
USE TradingTraining;
GO
SELECT DB_NAME() AS current_database;
SELECT name FROM sys.tables ORDER BY name;
SELECT TOP (5) * FROM dbo.instruments ORDER BY instrument_id;
```

Команда `USE` меняет контекст текущего подключения. `GO` — разделитель пакетов **в SSMS**, а не самостоятельный оператор T-SQL. Псевдоним `AS` задаёт имя столбцу результата.

**Что такое метаданные?** `sys.tables` — системное представление с информацией о таблицах. Запрос к нему — тот же SQL, только не к бизнес-данным.

## Термины

- **Строка (row)** — один объект/факт, например сделка.
- **Столбец (column)** — атрибут: `price`, `trade_date`.
- **Ключ (key)** — идентификатор/правило уникальности.
- **Schema** — пространство имён для объектов внутри БД; не путай со схемой отношений в диаграмме ER.
- **Query result** — логический набор строк, а не отдельная физическая таблица.
