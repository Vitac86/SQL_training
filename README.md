# SQL Training — последовательный курс SQL Server + SSMS

**Это курс с нуля до самостоятельной работы с реляционной БД и T-SQL.** Все примеры — на одной учебной базе с финансовыми инструментами, счетами, сделками и ценами. Уроки написаны так, чтобы новые команды опирались на уже изученные: **объяснение обычными словами → короткий пример → результат → почему так → самостоятельное упражнение**.

Рабочие инструменты: **Microsoft SQL Server** (сервер БД) и **SSMS** (приложение для запросов). Python и SQLite для прохождения курса не нужны.

## Если база уже создана

Раз твой `03_check.sql` показал 12 инструментов, 6 счетов, 230 сделок, 429 дневных цен и 429 записей ликвидности, **установка завершена**. Не нужно повторно запускать создание базы и загрузку данных. Начинай с [урока 00](lessons/00_первое_знакомство.md).

Если базы пока нет, смотри [пошаговую установку и подключение](SETUP_WINDOWS.md).

## Как устроено обучение

Курс состоит из **21 урока (00–20)**. В каждом уроке:

1. **Что уже знакомо** — короткое напоминание о том, на что опираемся.
2. **Новое понятие** — через знакомую задачу, без преждевременного профессионального жаргона.
3. **Несколько запросов**, которые можно выполнить в SSMS.
4. **Что должно получиться** и почему.
5. **Задания для самостоятельной проверки**.
6. Переход к **следующему** уроку.

**Знакомство с SSMS не вынесено в отдельный предмет.** В начале ты научишься открывать таблицы и выполнять SELECT; когда будем говорить о типах и ключах — откроем соответствующие узлы Object Explorer; когда дойдём до индексов и бэкапов — освоим именно эти инструменты SSMS.

В [уроке 05](lessons/05_создание_таблицы_и_check.md) ты **сам создашь маленькую таблицу** с `CHECK (quantity > 0)` и проверишь, что SQL Server отклоняет запись с количеством `-10`. Именно там объясняется, где задаётся ограничение, почему оно действует при INSERT и как найти его в SSMS. `TRY/CATCH` и разбор ошибок как отдельная тема появятся только в [уроке 13](lessons/13_транзакции_и_ошибки.md).

## Маршрут курса

Подробный порядок с зависимостями — [LEARNING_PATH.md](LEARNING_PATH.md).

**Первые 6 уроков (00–05):** знакомство с данными и SSMS, SELECT, фильтрация, типы данных, PK/FK и создание собственных ограничений.

**Уроки 06–11:** агрегаты, JOIN, изменение данных с откатом, подзапросы и CTE, точность финансовых чисел, оконные функции.

**Уроки 12–16:** проектирование и нормализация, транзакции и ошибки, параллельная работа, индексы и планы выполнения, VIEW/PROCEDURE/#temp.

**Уроки 17–20:** права, резервное копирование, контроль качества, самостоятельный проект «поручения и исполнения».

[Короткий словарь терминов](GLOSSARY.md) — справочник по мере прохождения; **не нужно заучивать его целиком заранее**.

## Как работать с файлами

- `lessons/` — основной учебник, по **одному уроку за раз**.
- `practice.sql` — черновик собственных запросов.
- `exercises.sql` — дополнительный практикум (задания пронумерованы и привязаны к урокам).
- `answers.sql` — решения к практикуму; заглядывай после попытки.
- `database/00_create_database.sql`, `01_schema.sql`, `02_seed_data.sql`, `03_check.sql` — **подготовка учебной среды**, не первые уроки по SQL. Эти скрипты настроили готовую базу **до изучения** CREATE TABLE и ограничений; позже ты сам увидишь, что они делают.
- `database/04_indexes_optional.sql` — дополнительный эксперимент с индексами после урока 15.
- `database/99_reset_data.sql` — защищённый сброс данных при необходимости (по умолчанию не удаляет ничего).
- `data/*.csv` — первоначальный синтетический набор; для использования он уже встроен в SQL-файл загрузки.
- `archive/sqlite/` — старый проект SQLite, сохранён для истории; **не нужен в основном курсе**.

## Набор данных и смысл примеров

- `dbo.instruments` — 12 инструментов, включая `TEST0` **без сделок**.
- `dbo.accounts` — 6 счетов, включая `ACC-DORMANT` **без сделок**.
- `dbo.trades` — 230 синтетических сделок BUY/SELL.
- `dbo.daily_prices` — 429 записей дневных цен.
- `dbo.liquidity` — 429 записей ликвидности.

Все данные **учебные**. Сумма `quantity * price` без учёта спецификации инструмента, валюты и множителя может быть математически корректной, но экономически не означать рублёвый оборот.

## Правила безопасности

В начале курса используем только SELECT. Создаваемые в уроках таблицы имеют имена `lesson05_...` и `lesson20_...`. Когда будем менять данные, сначала разберёмся с `WHERE` и `ROLLBACK`; учебные UPDATE/DELETE выполняются внутри транзакций с откатом. **Не запускай эти упражнения в боевой БД.**
